Privacy

Last updated Sun 18 Oct 2026

Nightcore Tracker is a static website. It has no user accounts, forms or comments, and the site itself sets no cookies and runs no analytics or tracking scripts.

Hosting

The site is hosted on GitHub Pages. GitHub may process technical data such as your IP address and request logs when you visit. See the GitHub General Privacy Statement.

Images from YouTube

Video thumbnails and channel avatars are loaded directly from YouTube and Google image servers (i.ytimg.com, yt3.ggpht.com, yt3.googleusercontent.com), so those providers receive your browser's request for each image. See the Google Privacy Policy.

External links

Links to YouTube, Linktree and other sites are governed by those sites' own privacy policies.

Ranking data

The rankings only use public YouTube statistics (view and subscriber counters, titles, names and images) of public videos and channels. No personal data about visitors is collected to produce them.

Advertising

Advertising is currently disabled. This page will be updated with the relevant details, including consent options, before any advertising is enabled.
